# Ravox BR

Interface personalizada para o YouTube. A versão 3.2.4 é distribuída como um userscript editável.

O endereço do projeto é [Tw0nin3/ravoxbr](https://github.com/Tw0nin3/ravoxbr). Quando a versão estiver publicada, procure `ravox-br.user.js` nos [Releases do projeto](https://github.com/Tw0nin3/ravoxbr/releases).

## Instalação e verificação

1. Baixe `ravox-br.user.js` da release oficial e abra o arquivo no seu gerenciador de userscripts.
2. Se quiser conferir os bytes antes de instalar, compare o SHA-256 do arquivo com o valor em `SHA256SUMS` no repositório oficial, na mesma tag da release. No PowerShell, use `Get-FileHash -Algorithm SHA256 ravox-br.user.js`.
3. Desative qualquer cópia antiga do Vértice ou uma instalação duplicada e recarregue o YouTube.
